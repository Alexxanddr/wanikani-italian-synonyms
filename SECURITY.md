# Sicurezza

## Versioni supportate

La versione più recente pubblicata è quella supportata.

## Segnalare una vulnerabilità

Non pubblicare dettagli sfruttabili in una issue. Usa **Report a vulnerability** nella scheda Security del repository GitHub. Includi impatto, condizioni necessarie e una procedura minima di riproduzione.

Non inviare cookie, credenziali WaniKani o contenuti sensibili.
