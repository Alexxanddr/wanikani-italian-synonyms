# Contribuire

## Segnalare un problema

Apri una issue descrivendo comportamento osservato e atteso, versione di Chrome e passaggi minimi per riprodurre il problema. Non includere cookie, token, password o altri dati sensibili.

## Proporre una modifica

1. Crea un fork e un branch dedicato.
2. Mantieni il codice privo di dipendenze quando possibile.
3. Verifica sintassi JavaScript e validità del manifest.
4. Prova il flusso su almeno un radicale, un kanji e un vocabolo.
5. Aggiorna README e CHANGELOG se il comportamento cambia.
6. Apri una pull request con descrizione e risultati delle prove.

## Stile

- JavaScript moderno senza framework.
- Due spazi per l'indentazione.
- Selettori DOM specifici, con fallback soltanto quando necessario.
- Nessuna telemetria o richiesta esterna senza discussione preventiva.
